📱 홈 화면에 앱처럼 추가하기

설치 없이, 사이트를 스마트폰 홈 화면에 아이콘으로 꺼내 둘 수 있어요. 누르면 주소창 없이 앱처럼 열려요.
사이트마다 따로 추가해요. 위에서 원하는 사이트에 먼저 들어간 다음 아래 순서대로 하면 돼요.

  1. Safari로 사이트를 열어요. (크롬 앱도 공유 버튼에서 같은 방법으로 돼요)
  2. 화면 아래(아이패드는 위)의 공유 버튼 을 눌러요.
  3. 목록을 아래로 내려서 홈 화면에 추가를 눌러요.
  4. 이름을 확인하고 오른쪽 위 추가를 누르면 끝!
  1. 크롬으로 사이트를 열어요.
  2. 오른쪽 위 점 세 개 메뉴 를 눌러요.
  3. 홈 화면에 추가 (또는 앱 설치)를 눌러요.
  4. 설치 또는 추가를 누르면 홈 화면에 아이콘이 생겨요.
  1. 삼성 인터넷으로 사이트를 열어요.
  2. 아래쪽 메뉴 버튼 을 눌러요.
  3. 현재 페이지 추가 → 홈 화면을 눌러요.
  4. 추가를 누르면 끝!

홈 화면 아이콘을 길게 눌러 삭제하면 언제든 지울 수 있어요. 저장된 API 키·테마 설정은 사이트마다 따로예요.
